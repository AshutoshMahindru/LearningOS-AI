# M08 deterministic regression dataset

`housing_regression.csv` contains 320 synthetic housing transactions generated by `generate_dataset.py` with Python's standard library and seed `8042`.

The fixture is local, deterministic, CPU-light and free of personal or external data. It is designed for learning and automated validation, not for claims about a real housing market.

## Columns

| Column | Meaning | Available at prediction time? |
| --- | --- | --- |
| `transaction_id` | Stable synthetic row identifier | yes, excluded as an identifier |
| `floor_area_m2` | Floor area | yes |
| `bedrooms` | Bedroom count | yes |
| `building_age_years` | Building age | yes |
| `distance_to_transit_km` | Distance to public transit | yes |
| `neighborhood_score` | Synthetic amenity/access score | yes |
| `renovation_quality` | Synthetic 1–5 condition rating | yes |
| `energy_efficiency` | Synthetic efficiency score | yes |
| `local_job_access_score` | Synthetic access-to-jobs score | yes |
| `post_sale_assessment_k` | Assessment created after the transaction | **no — controlled leakage fixture** |
| `sale_price_k` | Continuous prediction target, in thousands | target |

The generator combines nonlinear feature effects, interactions and irreducible noise. `post_sale_assessment_k` is intentionally derived from the target after the sale. A robust system must exclude it based on availability, even if it produces excellent cross-validation results.

Regenerate from the repository root with:

```bash
python3 datasets/M08/generate_dataset.py
```
