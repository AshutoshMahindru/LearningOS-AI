# WP-127: Retention and Evidence Decay Model

## 1. Spaced Repetition for System Architects
Complex architectural instincts decay unless refreshed. LearningOS tracks an exponential memory decay function for every mastered knowledge node based on Ebbinghaus intervals (1 day, 3 days, 7 days, 14 days, 30 days, 90 days).

## 2. Evidence Half-Life & Decay Rules
- An accepted competency certification remains at **L3 (Proven)** for 14 days.
- If no review or application occurs, competency decays to **L2 (Rusty)**.
- Daily "Today" recommendations prioritize 5–10 minute retrieval drills (code-reading or bug diagnosis) for decaying competencies.
- Successful completion of a retention drill refreshes the stability interval and restores the competency level.
