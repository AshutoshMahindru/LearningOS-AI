# WP-128: Progressive-Autonomy Model

## 1. Principle of Earned Autonomy
An apprentice does not start with full AI-generation privileges. Autonomy to use generative AI code synthesis is earned through proven, unassisted comprehension of lower-level primitives.

## 2. Autonomy Tiers

| Tier | Level Name | AI Generation Rights | Prerequisite Evidence |
|---|---|---|---|
| **Tier 0** | Syntax Apprentice | **0% AI** (Manual typing only) | Entry to platform |
| **Tier 1** | Scaffolding User | Socratic questioning & doc hints | Mastered M01–M07 (Phase 1) |
| **Tier 2** | Controlled Copilot | Autocomplete for boilerplate only | Mastered Phase 2 & Math Foundations |
| **Tier 3** | Agent Director | Multi-line agentic generation | Proven No-AI on Deep Learning (Phase 4) |
| **Tier 4** | Autonomous Architect| Full agent delegation with review | Complete Capstone (M42) |

## 3. Runtime Enforcement
The execution worker and IDE integration check the learner's active tier before enabling code completion plugins or automated agent synthesis tools.
