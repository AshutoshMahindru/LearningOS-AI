# Zoom Controller

When the learner is blocked:
1. Name the exact blocked mission step.
2. Identify the narrowest prerequisite responsible.
3. Open one bounded side quest, normally <=120 minutes.
4. Select the shallowest useful content depth.
5. Require prediction, experiment, explanation, and a micro-assessment.
6. Close the side quest after competence is sufficient.
7. Return to the exact blocked mission step.

Never let a side quest silently become a new curriculum branch.
