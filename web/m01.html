Mission objective

See the whole system before learning the pieces.

Experience a working AI/ML system, map it, interrogate it, run prediction-gated experiments, break and repair your model, then prove independent transfer.

WHOLE → MAP → INTERROGATE → PREDICT → RUN → OBSERVE → EXPLAIN → BREAK → NO-AI → TRANSFER → GATE

1. Whole first

First run the complete toy system once. LearningOS will show only the coarse event trace here; experiment-specific comparisons stay hidden until you commit predictions later.
Now describe what you think happened without studying internals.

2. Map your first mental model

Create a rough diagram or structured ASCII map. Include data, representation, training, model state, inference, prediction, application, retrieval, tools, memory, evaluation, observability and infrastructure. Mark data flow and control flow. It may be wrong.

3. Interrogate

Turn confusion into testable questions. Ask what changes state, what remains fixed, and what observation could falsify your explanation.

4. Prediction-gated experiments

Complete E1–E5 in order. For every experiment: commit prediction → run → inspect output → explain what the observation means. Future outcomes stay locked.

5. Break & repair

After E5, repair the deliberately confused architecture and justify each correction using behavior and evidence.

6. Explain

Explain training, learned state, inference, retrieval, controller/tools, memory, evaluation and observability in your own words. State the evidence that supports your boundaries.

7. No-AI reconstruction

Beginning this stage hides all earlier learning material in this workspace and locks the M01 tutor. Reconstruct the system from memory, explain boundaries, then map the fresh document-chat scenario.
No-AI mode not started.

8. Unseen transfer

Map a fresh AI architecture that was not used in the walkthrough. State assumptions and uncertainty. Do not invent a training step if none is described.
