Mission objective

See the whole AI system before learning the pieces.

By the end of M01 you should be able to inspect an unfamiliar AI application, identify its major layers, and explain what data, control and state cross each boundary.

WHOLE → MAP → INTERROGATE → PREDICT → RUN → OBSERVE → EXPLAIN → BREAK → NO-AI → TRANSFER → GATE

1. Whole first

Do not study internals yet. The system contains labelled data, training, learned state, inference, retrieval, a controller, an external tool, application memory, evaluation and runtime traces. Your task is only to describe what you think the whole system is doing.

2. Map your first mental model

Create a rough architecture in text or ASCII. Include data, representation, training, model state, inference, prediction, application, retrieval, tools, memory, evaluation, observability and infrastructure. Mark data flow and control flow. It is allowed to be wrong.

3. Interrogate your map

Turn uncertainty into testable questions. Focus on what changes state, what remains fixed, and what observation could falsify your current explanation.

4. Prediction-gated experiments

This is the core of M01. Each experiment must be completed in order: commit a prediction → run → inspect the visible output → explain what the observation means. The app will not reveal an experiment before your prediction is saved.

5. Break & repair

E5 deliberately presents a confused architecture. After E5, write the repaired architecture and justify the correction using observed behavior rather than vocabulary alone.

6. Explain the system

Explain the mechanism in your own words: what training changes, what inference normally does not change, how retrieval changes context without retraining, how tools/controller/memory differ, and how evaluation/observability fit around the system.

7. No-AI reconstruction

When you begin, stop using the tutor, search, references and this page's earlier sections. Reconstruct the architecture from memory, explain the major boundaries, and identify the layers in the fresh document-chat scenario.
No-AI mode not started.

8. Unseen transfer

Map a fresh AI architecture that was not used in the walkthrough. State assumptions explicitly. Do not invent a training step when the system description contains none.

9. M01 evidence contract

The formal gate is unlocked only when the mission-specific evidence is present. Clicking through stages cannot substitute for evidence.
