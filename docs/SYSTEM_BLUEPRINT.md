# LearningOS-AI System Blueprint

## Mission
Build an adaptive AI apprenticeship system that develops an AI Systems Architect/Builder.

## Architecture

### Learning Design Layer
- Outcome model
- Competency graph
- Knowledge graph
- Mission graph
- Content map

### Runtime Layer
1. Select mission
2. Start from whole system
3. Map and interrogate
4. Use canonical content
5. Experiment
6. Zoom in only when blocked
7. Rebuild
8. Break and debug
9. Explain
10. Transfer without AI
11. Pass competency gate

### Apprenticeship Controls
- No-AI competency blocks
- Code reading
- Chaos days
- ADRs
- Reviews
- Git evidence
- Progressive AI autonomy

### Adaptive Components
- Learner model
- Tutor orchestration
- Content routing
- Side quests
- Competency repair

## Core Principle

Start with the useful whole. Descend only as needed. Return to the whole.
