# Apprenticeship Controls

The merged system imports engineering apprenticeship discipline.

## Mandatory Controls

### No-AI Gate
Every mission contains independent execution time.

### Code Reading
Read unfamiliar code and explain flow, state and assumptions.

### Chaos Day
Diagnose deliberately broken systems from symptoms to root cause.

### ADRs
Record consequential technical decisions.

### Reviews
Periodic principal-engineer style reviews.

### Progressive AI Autonomy
AI assistance increases only after demonstrated independent competence.

### Evidence
Competence requires artifacts, explanations, experiments or reviews.
