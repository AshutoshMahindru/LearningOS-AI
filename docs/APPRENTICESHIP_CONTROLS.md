# Apprenticeship Controls

The merged system imports engineering apprenticeship discipline.

## Mandatory Controls

### No-AI Gate
Every mission contains independent execution time. The learner must demonstrate capability without generated implementation.

### Code Reading
Every coding cycle includes unfamiliar artifact reading:
- trace inputs and outputs
- explain flow and state
- identify assumptions
- predict behaviour before execution

### Chaos Day
Every two missions include deliberately broken systems. The learner diagnoses symptoms, hypotheses, experiments and root causes.

### ADRs
Consequential technical decisions require Architecture Decision Records:
- context
- decision
- alternatives
- evidence
- consequences
- revisit conditions

### Reviews
Periodic principal-engineer reviews require defending decisions and reasoning about feedback.

### Progressive AI Autonomy
AI assistance increases only after demonstrated independent competence.

Levels:
1. Apprentice - AI explains and assists.
2. Builder - AI implements bounded components.
3. Architect - AI builds subsystems under specifications.
4. Lead - AI operates under system-level direction.

### Evidence
Competence requires artifacts:
- code
- experiments
- explanations
- reviews
- ADRs
- demonstrations
