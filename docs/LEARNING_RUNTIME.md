# Learning Runtime

## Mission Loop

```text
MISSION
  ↓
WHOLE FIRST
  ↓
MAP THE SYSTEM
  ↓
INTERROGATE
  ↓
MANIPULATE
  ↓
DESCEND ONLY WHEN BLOCKED
  ↓
DECOMPOSE
  ↓
REBUILD
  ↓
BREAK
  ↓
EXPLAIN
  ↓
TRANSFER WITHOUT AI
  ↓
COMPETENCY GATE
  ↓
EVIDENCE
```

## Session Pattern

1. Experience the complete system.
2. Predict before changing variables.
3. Experiment and observe.
4. Read implementation details.
5. Build a simplified version.
6. Diagnose failures.
7. Explain without notes.
8. Record evidence.

## Zoom Controller

When blocked:

```text
Mission
 ↓
Identify blocker
 ↓
Find prerequisite
 ↓
Learn minimum required depth
 ↓
Pass micro assessment
 ↓
Return to mission
```

The main mission remains the anchor.

The system optimizes for demonstrated competence rather than completion.
