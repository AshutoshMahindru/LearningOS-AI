# No-AI transfer gate

Without AI-generated code, create a fresh two- or three-dimensional query and at least three named candidates.

Before calculating:

1. label every dimension;
2. predict the cosine and Euclidean winners;
3. state whether vector magnitude should carry meaning in this scenario;
4. choose a metric and explain the invariant it measures.

Then calculate both rankings, check the normalization boundary, and explain any disagreement. The gate passes only when the learner can implement the core operations, find or construct a disagreement case, and defend a metric choice on fresh data without copying the lab fixture.
