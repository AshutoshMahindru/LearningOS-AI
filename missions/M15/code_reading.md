# Code-reading exercise

Read the notebook's `rank_vectors` function without running it.

Record:

1. how it validates the query and each candidate;
2. which metrics are ordered from high to low and which from low to high;
3. how a deterministic tie is resolved;
4. where magnitude affects the result;
5. which error is raised for an unsupported metric;
6. one input that should be rejected and why.

Then trace two candidates by hand and predict the returned order before executing the cell. Evidence must contain the trace, not only the final ranking.
