# M08 No-AI Gate

Complete a 30–60 minute transfer exercise **without AI-generated code or prose**.

Use a fresh continuous-outcome dataset that is not the bundled M08 housing data. You may consult official library documentation.

Required work:

1. define the prediction moment, target and permitted feature set;
2. state a prediction before running each material experiment;
3. implement a baseline and one regression model;
4. preserve a held-out test set;
5. report MAE, RMSE and R² with correct interpretation;
6. create and diagnose at least one residual plot;
7. use cross-validation on training data;
8. demonstrate either underfitting or overfitting;
9. audit every feature for availability and leakage;
10. explain one uncertainty and one prevention control.

Transfer passes only when the result is reproducible, the evaluation boundary is intact and the learner can explain the system without relying on generated narration.
