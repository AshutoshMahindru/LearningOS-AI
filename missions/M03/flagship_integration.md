# V01 — Structured Data Workbench integration

M03 supplies the programming modification and debugging layer used by V01.

The learner should carry these habits into the workbench:

- run a working pipeline before changing it;
- inspect inputs and outputs;
- predict the effect of a transformation;
- change one behavior at a time;
- trace intermediate state;
- distinguish syntax/runtime errors from logic errors;
- preserve unrelated behavior;
- verify repairs with representative and boundary cases.

M03 evidence can be reused in V01 as proof that the learner can safely alter unfamiliar Python rather than only reproduce memorized syntax.
