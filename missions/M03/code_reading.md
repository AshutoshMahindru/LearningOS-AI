# Code reading

Read an unfamiliar short Python function before modifying it.

For every pass identify:

1. inputs;
2. output;
3. mutable data;
4. loop iterations;
5. conditions;
6. function calls;
7. intermediate values;
8. side effects.

Before executing, manually trace at least one input and predict the result.

Then execute the function and compare your prediction with the observed value.

If they differ, identify the first line where your mental trace diverged from execution.

Finally make one requested behavior change without rewriting the whole function.
