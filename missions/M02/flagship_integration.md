# M02 Integration with V00

M02 supplies the first executable vertical slice of V00: a learner can move from local raw data to an evidence-backed model result before the curriculum decomposes individual mechanisms. The mission establishes a common system vocabulary—features, target, split, fit, prediction, evaluation, and interrogation—that later missions can refine without changing the overall map.

The experiment log makes V00 an interrogable system rather than a one-click demo. Split, features, model, hyperparameter, label integrity, and evaluation setup become explicit controls. The controlled failures introduce a crucial V00 guardrail: executable code and impressive metrics are not automatically valid evidence.

The no-AI gate supplies transfer evidence. A reviewer should accept M02 integration only when the learner can recreate a fresh supervised run, point to the learning and evaluation boundaries, diagnose misleading evidence, and state limitations. M02 does not claim production fitness, causal knowledge, or broad generalization from the Wine benchmark.
